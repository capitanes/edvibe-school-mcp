Подключение

Четыре шага

Настройка занимает 5 минут: вам понадобятся ключ из личного кабинета и готовый блок настроек для редактора.

  1. 01

    Проверьте раздел в кабинете

    Откройте «Настройки» в вашей школе Edvibe и убедитесь, что раздел API доступен для выпуска ключа.

  2. 02

    Получите API-ключ

    Создайте ключ в настройках школы. Не отправляйте его в чат и не добавляйте в общие документы.

  3. 03

    Добавьте в настройки MCP

    Выберите клиент ниже, скопируйте JSON или TOML в конфигурационный файл MCP и укажите свой ключ и домен.

  4. 04

    Проверьте чтение

    После перезапуска клиента попросите показать занятия на сегодня. Это не меняет данные школы.

// ~/.cursor/mcp.json — удалённое подключение
{
  "mcpServers": {
    "edvibe": {
      "type": "streamable-http",
      "url": "https://edvibe.sungurov.com/mcp",
      "headers": {
        "Authorization": "Bearer <EDVIBE_API_KEY>", // замените только <EDVIBE_API_KEY> на ваш ключ. Ключ можно сгенерировать в личном кабинете в разделе API: https://edvibe.com/cabinet/school/settings/api?tab=settings
        "X-Edvibe-School-Domain": "edvibe.com" // для White Label замените на свой домен
      }
    }
  }
}
# ~/.codex/config.toml — удалённое подключение
[mcp_servers.edvibe]
type = "streamable-http"
url = "https://edvibe.sungurov.com/mcp"

[mcp_servers.edvibe.headers]
Authorization = "Bearer <EDVIBE_API_KEY>" # замените только <EDVIBE_API_KEY> на ваш ключ. Ключ можно сгенерировать в личном кабинете в разделе API: https://edvibe.com/cabinet/school/settings/api?tab=settings
X-Edvibe-School-Domain = "edvibe.com" # для White Label замените на свой домен
// ~/.config/devin/mcp_config.json — удалённое подключение
{
  "edvibe": {
    "type": "streamableHttp",
    "url": "https://edvibe.sungurov.com/mcp",
    "headers": {
      "Authorization": "Bearer <EDVIBE_API_KEY>", // замените только <EDVIBE_API_KEY> на ваш ключ. Ключ можно сгенерировать в личном кабинете в разделе API: https://edvibe.com/cabinet/school/settings/api?tab=settings
      "X-Edvibe-School-Domain": "edvibe.com" // для White Label замените на свой домен
    }
  }
}

edvibe.com — домен по умолчанию. Если у вас подключён White Label, замените его на свой домен школы (без https://, порта и пути). Сервер — личный пилотный стенд, а не официальный сервис Edvibe.

Безопасность и контроль

Ваши данные и ключ остаются под вашим контролем

Сервер не сохраняет пароли и базы данных. Чтение происходит мгновенно, а любые изменения требуют вашего подтверждения в редакторе.

Безопасно по умолчанию

Ключ и данные под защитой

  • Ключ хранится только на вашем компьютере в настройках клиента.
  • 35 методов чтения работают без риска изменения данных.
  • Запросы отправляются по защищённому HTTPS-соединению.
  • Сессии разных школ строго изолированы друг от друга.

Защита от случайных действий

Ничего не меняется без вашего одобрения

  • Любое создание, перенос или удаление запрашивает подтверждение.
  • 17 операций повышенного риска показывают превью затронутых записей.
  • Встроенный лимит защищает школу от случайной перегрузки API.
  • Никаких скрытых списаний уроков без вашего явного одобрения.

Ключ не нужно передавать нам

При локальном подключении он хранится в конфигурации вашего клиента. На личном HTTP-стенде ключ приходит с конкретным запросом и не должен сохраняться в базе, логах или кэше.

FAQ

Коротко о главном

Кому доступен Edvibe MCP?

Школам Edvibe с подключённым School API. В первой версии это школы на тарифе Pro или с отдельно открытым API-модулем.

Это официальный сервис Edvibe?

Нет. Сейчас это пилотный проект. Официальный релиз ожидается после завершения всех этапов тестирования и закрытой беты.

Может ли ассистент изменить данные?

Да, School API содержит операции создания, обновления и удаления. Клиент должен запросить ваше подтверждение перед записью. В пилоте рекомендуется начинать с операций чтения.

Когда лучше использовать MCP, а когда прямую интеграцию через API?

MCP отлично справляется с гибкими и оперативными задачами — когда нужно быстро найти данные, перенести группы или собрать нестандартную сводку словами через чат. Но если вы ежедневно выполняете одни и те же строго регламентированные массовые операции (например, регулярную синхронизацию с CRM или фоновый биллинг), для таких сценариев надёжнее настроить прямую автоматизацию через API.

Работает ли White Label?

Да. Если у вас подключён White Label и школа работает на собственном домене, просто укажите его в поле домена в настройках конфигурации MCP.
